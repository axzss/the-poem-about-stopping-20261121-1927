Entry for the make.fun bounty [The poem about stopping](https://make.fun/competitions/the-poem-about-stopping-20261121-1927): a program that writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt`.

## The poem

> At the crosswalk, rain beads on my untied shoe.
> The walk sign blinks; I could give the street my weight.
> Instead I knot the lace, slowly,
> while the green drains out.
> Somewhere behind me, my daughter stops too.

209 characters. A person chooses not to cross; the staying passes to the child behind them.

## Run

```sh
python3 main.py   # writes entry.txt to /output (or $MAKEFUN_OUTPUT_DIR)
```

Deterministic, no network, no input — every run writes exactly the same bytes.
